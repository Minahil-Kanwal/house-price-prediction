# Models

`house_price_pipeline.joblib` and `model_metadata.json` are generated by `python -m src.cli train --download` and excluded from git. The serialized pipeline contains feature engineering, imputation, encoding, and the final estimator, so inference does not need a separate scaler or encoder artifact.

Only load artifacts produced in a trusted environment: Joblib/pickle-based files can execute code during deserialization.
